格式作坊 —— 通用格式转换器（图片 / 视频 / 音频）
====================================================

一、这是什么
------------
一个本地转换工具，左侧三个按钮切换三个板块：图片、视频、音频。
界面沿用 kgg-mp3 的液态玻璃风格，转换内核是 FFmpeg，音频板块额外
保留了 KGM2 的酷狗加密音乐解密链（KGG / KGM / KGMA / NCM），
并内置了网易云 NCM 与 QQ 音乐 QMC 的解密支持。

全程本地处理，不上传任何音频文件，不覆盖源文件。
安装后约 165 MB（其中 FFmpeg 本体 100 MB）。

二、安装与卸载
--------------
安装：双击安装包 → 选择安装位置（默认在
      C:\Users\<你>\AppData\Local\格式作坊，可改到任意盘）→ 完成。
      安装器会自动创建桌面快捷方式和开始菜单项。

卸载：设置 → 应用 → 已安装的应用 → 找到 格式作坊 → 卸载；
      或在开始菜单的 格式作坊 文件夹里运行卸载。

三、怎么用
----------
1. 双击桌面“格式作坊”
2. 左侧点“图片转换 / 视频转换 / 音频转换”切换板块
3. 拖入文件，或点“选择文件…”（可多选，也可以选整个文件夹）
4. 右侧选输出格式和选项，点“开始转换”

成品在 output 文件夹，日志在 logs 文件夹。
“保存位置”可以改到别处，也可以勾选“保存到源文件夹”。

四、右键菜单（安装后首次启动时自动写入）
----------------------------------------
右键任意文件 / 文件夹 / 文件夹空白处，都会出现「用 格式作坊 转换」，
展开后是三个选项：

    转为图片    → 打开图片板块
    转为视频    → 打开视频板块
    转为音频    → 打开音频板块（视频也能选这项，会把音轨提取出来）

菜单只写进当前用户（HKCU），不需要管理员权限。一次选中多个文件时，
Windows 会为每个文件单独拉起一次程序；想要批量转换，建议在程序里
框选或拖入整个文件夹。

五、三个板块各自能做什么（输入格式不限于下面列出的，只要 FFmpeg 能解码就会自动识别并接纳）
------------------------
【图片转换】
  输入：jpg / jpeg / png / webp / bmp / tif / tiff / gif / ico / tga / ppm / psd / dds 等
  输出：PNG（无损）/ JPG（通用）/ WEBP（最小）/ BMP / TIFF
  尺寸：原尺寸 / 最大边 1920 / 1280 / 800 / 缩小一半
  画质：高质量 / 标准 / 小体积（JPG、WEBP 生效）
  说明：缩放只缩小不放大；JPG 会把透明区域变成白色。

【视频转换】
  输入：mp4 / mkv / avi / mov / webm / flv / wmv / ts / m4v / mpg / mpeg / 3gp / ogv / m2ts / vob / rmvb / mxf 等
  输出：MP4·H.264 / MKV·H.264 / MOV·H.264 / WEBM·VP9 / AVI·MPEG-4 / GIF
  分辨率：原分辨率 / 1080p / 720p / 480p
  质量：高质量（CRF 18）/ 标准（CRF 23）/ 小体积（CRF 28）
  说明：MP4 兼容性最好，WEBM 同画质体积更小；GIF 导出 12 帧动图、无声音。

【音频转换】
  输入：mp3 / wav / aac / m4a / flac / ogg / wma / opus / ape / ac3 / dts / amr / mka / wv 等
  加密音乐（自动解密）：
    酷狗    kgg / gkk / kgm / kgma / kge / kgtemp / vpr
    网易云  ncm
    QQ 音乐 qmc0 / qmc2 / qmc3 / qmcflac / qmcogg
            mflac / mflac0 / mflach / mgg / mgg0 / mgg1 / mggl
  输出：MP3 / WAV / FLAC / M4A / OGG / OPUS / WMA
  音质：高质量 / 标准 / 省空间（仅 MP3 生效）
  说明：原始 MP3 转 MP3 会直接无损输出，不重新编码。

六、QQ 音乐新版格式（musicex）需要登录凭据
------------------------------------------
QQ 音乐 19.57 之后下载的 .mflac / .mgg 不再把密钥写进文件，需要向官方
接口换 ekey。程序会自动尝试：
  1. 读取 %APPDATA%\Tencent\QQMusic\QQMusicServiceConfig.ini 里的账号
  2. 从正在运行的 QQMusic.exe 进程内存里读取 authst（不会上传任何文件）
  3. 用这两项调用 GetEVkey 接口换取该曲的 ekey

所以遇到这类文件时：请先启动 QQ 音乐并保持登录，再去转换。
如果没装/没登录，程序会明确提示，不会静默失败。
“引擎状态与工具…”里可以看到 QQ 音乐凭据是否就绪。

七、界面上的其他按钮
--------------------
  打开输出文件夹 / 打开日志文件夹：直接打开对应目录
  引擎状态与工具…：查看 FFmpeg、各解密工具、酷狗数据库、QQ 凭据状态
  查看转换日志：当前板块最近一次转换的完整过程
  移除选中 / 清空列表：管理队列
  同时转换：并行任务数（1–8）

八、命令行用法（绿色版）
------------------------
安装包只提供图形界面；绿色版目录里的 格式作坊-cli.exe 是命令行程序：
  格式作坊-cli.exe <输入文件> [输出文件夹] [格式]
例如：
  格式作坊-cli.exe "D:\pics\a.jpg" "D:\out" WEBP
  格式作坊-cli.exe "D:\video\a.mp4" "D:\out" WEBM
  格式作坊-cli.exe "D:\music\a.kgm" "D:\out" FLAC
格式：图片 PNG/JPG/WEBP/BMP/TIFF；视频 MP4/MKV/MOV/WEBM/AVI/GIF；
      音频 MP3/WAV/FLAC/M4A/OGG/OPUS/WMA。不填则按板块默认。

九、已知限制
------------
· KGM/KGMA 的掩码只覆盖 64 MB 音频；64–78 MB 会自动改用 KGM2 的工具，
  超过 78 MB 会明确报错（原版工具也会输出被截断的坏文件）。
· QQ 音乐 musicex 新格式必须能拿到在线 ekey（见第六节）。
· HEIC / AVIF 无法解码（当前 FFmpeg 构建不含这两种解码器）。
· GIF 输出固定 12 帧、无声；需要完整视频请选 MP4/WEBM。
· 视频转码是 CPU 编码，长视频会比较慢，可调高“同时转换”。

十、目录说明
------------
格式作坊.exe       主程序
格式作坊-cli.exe   命令行版
app\                 程序、FFmpeg 与解密工具
runtime\             内置 Java 运行时（精简版，无需另装 Java）
output\              转换结果
logs\                每次转换的日志
